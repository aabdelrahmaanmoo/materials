# Materials

Course materials platform for 4th-year students, Department of Agricultural Engineering. Lectures, sections and textbooks for every subject, organized by specialization and built for phones.

This repository hosts the public showcase page and a short link to the app. The app itself runs on Google Apps Script with Google Drive as storage.

## Structure

| File | Purpose |
|---|---|
| `index.html` | Showcase page (Arabic, RTL): features, how to join, home-screen shortcut, FAQ |
| `app/index.html` | Redirects to the Apps Script web app |
| `guide/index.html` | Admin guide (Arabic, RTL): approvals, uploads, subjects, sync, troubleshooting |

## Brand

- Wordmark: `Materials` in Cairo 900 with a 3px offset shadow.
- Colors: forest `#0E4A2C` and lime `#D7F23B`; neutrals tinted green.
- Light and dark themes follow the device setting.
